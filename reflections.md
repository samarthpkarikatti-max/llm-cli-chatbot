# Prompt Engineering Experiments

## 1. System Prompt Experiments

### Experiment 1: Coding Tutor
Temperature: 0.2

Observation:
The chatbot explained programming concepts in simple
language and provided examples to help understand
technical topics.

### Experiment 2: Interview Assistant
Temperature: 0.5

Observation:
The chatbot provided structured and professional
answers suitable for technical and HR interviews.

### Experiment 3: Friendly Assistant
Temperature: 1.0

Observation:
The chatbot responded in a friendly and conversational
manner and provided detailed explanations.

## 2. Temperature Experiment

The same system prompt and question were tested
using different temperature values.

- 0.2: Responses were generally more predictable
  and consistent.
- 0.5: Responses provided a balance between
  consistency and variation.
- 1.0: Responses showed more variation and creativity.

## 3. Learning Outcomes

### What is a system prompt?
A system prompt defines the role, behaviour and
instructions of an AI chatbot.

### Why does it change chatbot behaviour?
It guides the AI to generate responses according
to the specified role and instructions.

### What does temperature do?
Temperature controls the randomness and variety
of generated responses.

### What was the trickiest part?
Connecting Python with the Groq API and maintaining
conversation history were the most challenging parts.
I learned how to store previous messages in a list
and send them to the LLM as conversation context.
